### C. Reconstruction investigation for 1.6Hz nowind runs (full, documented below)

Extensive investigation into why run2 IN FFT = 14.4 mm vs expected ~20 mm.

**Root cause**: Phase-locked probe fault artifact at post-trough rising phase (0.55–0.85 of
period). Slow descent (2–3 mm/sample) stays below `DIFF_MONO_MM=3.5` threshold — trough
flanks remain as "clean" non-NaN samples, but pull the FFT amplitude down.

**Period overlay** (`analysis_scratch/period_overlay.py`): stacks upcrossing-to-upcrossing
periods on top of each other. Confirms:
- ALL 23 periods in run2 have post-trough distortion at exactly the same phase (0.6–0.85)
- 6 "severe" (min < -40mm), 17 "indent" (min in window < -12mm, above -40mm)
- run3, run4: 1 severe, 22 indent each — same mechanism, different severity
- Zero genuinely clean periods in any of the three runs

**Reconstruction approach — Variant B (iterative sigma-clip + amp gate + derivative fill)**

`analysis_scratch/reconstruct_all3.py` applies this to run2, run3, run4:

1. **Iterative sigma-clip (3σ, max 10 iterations)**: fit LSQ sine to non-NaN samples →
   flag |residual| > 3σ → refit → repeat until convergence. 7 iterations for run2.
2. **Amplitude gate (post-convergence)**: flag samples below `mean - amp × 1.3` or above
   `mean + amp × 1.3`. Catches trough flanks whose local residual was within 3σ but whose
   absolute level is impossible for a wave of this amplitude.
3. **Final refit on remaining clean samples**: produces the LSQ sine used for reconstruction.
4. **Edge buffer (±4 samples)**: dilate nan_mask around every gap boundary — catches
   probe-settling samples at re-entry that are within 3σ individually but still distorted.
5. **Derivative-guided fill** (see below): fills each gap anchored to actual signal at
   boundaries, uses sine only for rate-of-change guidance.

**Reconstruction results (2026-04-15):**
```
run2: orig_fft=14.46mm  recon_fft=21.22mm  460 new samples flagged  sev:6→0  ind:17→23  cln:0→0
run3: orig_fft=20.15mm  recon_fft=21.65mm  174 new samples flagged  sev:1→0  ind:22→23  cln:0→0
run4: orig_fft=20.33mm  recon_fft=21.20mm   98 new samples flagged  sev:1→0  ind:22→23  cln:0→0
```

**Mean of recon FFT values**: (21.22 + 21.65 + 21.20) / 3 ≈ **21.36 mm**. Consistent with
per240 runs and the amplitude input (0.3V → ~20mm).

### D. Derivative-guided fill (the key innovation)

**Problem**: filling NaN gaps with `sig_recon[nan_mask] = sine[nan_mask]` produced "cliff"
artifacts at gap re-entry boundaries (visible at t≈27.4s and t≈31.8s in run2). The sine
value at gap end ≠ raw signal value just after re-entry → 1-sample step discontinuity.

**Reason the plain sine fails**: LSQ sine has a global amplitude that doesn't match
period-to-period amplitude variation in the real signal.

**Solution — per-gap derivative-guided blend**:

For each gap [g_start, g_end]:
- `i_L` = last clean sample before gap (left anchor), `i_R` = first clean sample after gap (right anchor)
- Forward extrapolation from left: `fwd[k] = sig[i_L] + (sine[k] - sine[i_L])`
- Backward extrapolation from right: `bwd[k] = sig[i_R] + (sine[k] - sine[i_R])`
- Blend by position: `sig_recon[k] = w_L × fwd + w_R × bwd` where `w_R = (k - g_start) / (gap_len + 1)`
- Edge cases (gap at start/end of window): use only the available anchor

This guarantees **continuity at both boundaries** — the reconstruction always matches the
real signal at `i_L` and `i_R` by construction (since `sine[i_L] - sine[i_L] = 0`).

The sine is NOT used directly as the amplitude reference — only its derivatives (shape/rate).
This preserves the per-period amplitude variation of the actual signal.

even in run3 and run4. The derivative-guided fill removes the severe cliff artifacts (t≈27.4s,
t≈31.8s) but does not heal the subtle per-period indents that remain as "kept" samples
(within the sigma-clip tolerance).

This means the reconstructed signal still has minor per-period distortion at phase 0.6–0.85.
For the purposes of FFT amplitude at 1.6 Hz, this is small — the recovered amplitudes
(21.2–21.7 mm) are self-consistent across the three runs.

For a period-domain analysis (e.g. crest/trough statistics) the indents would matter more.
That analysis is not currently planned.
