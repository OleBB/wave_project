## Finding #1 — per240 discrepancy is a WINDOWING ARTIFACT, not reflection buildup

The last agent ran a sliding-window FFT on per240 fullwind 1.3 Hz runs at 9373/170.
Result in `analysis_scratch/sliding_afft_per240.pdf`.

**What the PDF shows** (4 panels + nowind reference):
- AFFT@1.3 Hz is stable at **~7.5 mm across the full duration of the run** (10–200 s for mstop30, 10–500 s for mstop330).
- The pipeline analysis window (21–39 s, shown in green) lands on a **temporary depression**. Pipeline reads AFFT = 6.34 / 7.41 / 5.28 / 4.50 mm across 4 runs.
- Mean AFFT over the whole stable portion of the run: **7.28–7.57 mm** (consistent across mstop30 and mstop330, consistent with nowind reference).

**Implication:** The per240 vs per40 AFFT/Atd discrepancy at 1.3 Hz fullwind 0.1V
(documented in `memory/open_question_per240_afft.md`) is **not reflection buildup**.
Reflections would appear as a drift after t≈35–38 s (round-trip from far wall).
The data shows the opposite: AFFT is LOW at the pipeline window and stable-higher everywhere else.

**Most likely cause**: the analysis window starts while some slow transient (wind-induced
phase jitter? coherence buildup?) is still settling. By t≈50 s onward the FFT peak has
stabilised.

**Open question**: is this specific to 1.3 Hz fullwind, or does it affect all fullwind
runs? If it is general, `_SNARVEI_CALIB` start values may need to be pushed later for
fullwind runs — or the windowing for fullwind may need different treatment entirely.

**Not yet investigated:**
- Does the same depression appear at 1.4, 1.5, 1.6 Hz fullwind?
- Does it appear at nowind (the reference run in the PDF looks fully stable)?
- What's the physical timescale — does the wind need N periods to settle?

## Finding #2 — the 1.3 Hz table reveals the r_9373/170 spread

`fft_vs_td_17apr.md` shows AFFT/Atd ratios per run at 1.3 Hz, for all probes.

Striking pattern: at fullwind 0.1V, `r_9373/170` ranges from 0.320 to 0.603 across
individual runs — large cycle-to-cycle / run-to-run variation at the IN probe.
Meanwhile `r_12400/250` (OUT probe, sheltered) is tightly clustered at 0.90–0.93.

This is consistent with finding #1: the IN probe under fullwind has a variable
relationship between FFT amplitude and time-domain amplitude that depends heavily
on exactly where the window is placed. The OUT probe does not have this problem.
